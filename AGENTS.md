# Project Pitch Perfect

## Purpose

Project Pitch Perfect is a music education and performance training platform supporting students, teachers, parents, schools, colleges, universities, and private instructors.

The authoritative project specifications are:

* Project_Pitch_Perfect_SRS_v1.docx
* Project_Pitch_Perfect_SRS_v1.pdf

## Development Instructions

Before generating code:

1. Read all project documentation.
2. Produce an implementation roadmap.
3. Identify missing requirements.
4. Recommend architecture improvements.

## Technology Stack

Backend:

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* Alembic

Frontend:

* React
* TypeScript

Authentication:

* JWT
* OAuth2
* Google Login
* Microsoft Login

Deployment:

* Docker
* GitHub Actions

## User Roles

* Student
* Teacher
* Parent
* Institution Administrator
* System Administrator

## Coding Standards

* Production-quality code
* Type hints required
* Automated tests required
* Security best practices required
* Documentation required

## First Task

Do not write application code immediately.

First generate:

1. System Architecture Specification
2. Database Design Specification
3. User Interface Specification
4. Implementation Roadmap
5. Development Milestones
6. Risk Assessment
7. Testing Strategy
8. Deployment Strategy

After approval, begin implementation in phases.
